# 舞伴智练 V1.4 集成视觉识别版｜开发说明

版本：1.4.0（本地单机试点）  
开发基线：V1.3学习原型 + V1.4视觉识别原型  
日期：2026-11-22

## 本次实际开发内容

### 1. 保留V1.3已有模块
- 学习首页
- 动作精讲
- 分段记忆陪练
- 动作衔接专项训练
- 现代舞知识
- AI舞伴（未配置在线模型时使用本地知识模式）
- 艺术表达
- 教师工作区

### 2. 新增视频视觉识别
- 教师创建现代舞课程。
- 教师上传标准示范视频（MP4/MOV/M4V/AVI，最大100MB，最长60秒）。
- MediaPipe Pose Landmarker提取每个抽样帧的33个人体姿态关键点。
- 输出带时间戳的结构化JSON、骨架预览视频、姿态关键帧联系表。
- 显示姿态检测比例；该比例只表示抽样帧检测情况，不是动作得分。

### 3. 新增教师审核与片段发布
- 教师可根据原始示范视频播放位置填写片段起止时间。
- 教师为片段命名并填写动作讲解。
- 新建片段默认“待教师审核”。
- 只有教师明确确认的片段才能发布到学员练习列表。
- 课程和片段元数据保存在本机SQLite数据库。

### 4. 新增学员练习视频对照
- 学员选择教师已发布课程和审核片段。
- 使用学员代号上传个人练习视频。
- 系统同样提取人体关键点并生成骨架预览。
- 标准视频与学员视频可并排播放，并分别查看骨架联系表。
- 当前仅提供并排观察，不生成自动动作评分或对错判断。

### 5. 本地隐私和删除
- 原始视频保存在storage/uploads随机ID文件名下。
- 姿态结果保存在storage/results对应随机ID目录。
- 原始视频不挂载为公开静态目录。
- 页面提供删除练习视频、删除课程及其关联视频/分析结果的入口。
- 上传前增加知情同意确认。

## 关键技术结构

- Web前端：保留V1.3单页应用，新增“AI视频识别”页面。
- API后端：FastAPI，统一端口8011。
- 视觉分析：独立vision/pose_service.py模块，使用MediaPipe Pose Landmarker。
- 视频处理：OpenCV。
- 本地数据：SQLite（data/vision.sqlite3）。
- 文件：storage/uploads和storage/results私有目录。
- AI文本：保留原有可选OpenAI兼容接口；未配置密钥时本地知识模式继续可用。

## 运行环境

- 推荐并要求Python 3.12（64-bit），不要使用Python 3.15环境运行MediaPipe。
- start_windows.bat会自动创建项目专属.venv、安装依赖、下载姿态模型并启动本地服务。
- 本项目默认绑定127.0.0.1:8011，不可直接开放公网。

## 目前不包含

- 用户账号、权限、多租户、跨设备同步。
- 云端视频存储和公开访问。
- 实时摄像头纠错。
- 自动舞蹈动作语义理解、自动编舞、舞姿总评分。
- 大学生兼职人才市场、社区活动报名、文化旅游交易。

这些功能应在真实试点后按阶段开发。
