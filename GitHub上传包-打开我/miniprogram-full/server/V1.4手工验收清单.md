# V1.4 手工验收清单

## A. 启动与环境
- [ ] 安装Python 3.12（64-bit）。
- [ ] 双击start_windows.bat，首次运行自动安装依赖并下载模型。
- [ ] 浏览器打开http://127.0.0.1:8011。
- [ ] `/api/health`返回ok=true、mediapipe_ready=true、model_ready=true。
- [ ] 原V1.3旧文件夹仍然保留，可独立回滚。

## B. V1.3回归
- [ ] 学习首页可打开。
- [ ] 动作精讲、记忆陪练、动作衔接可用。
- [ ] 舞蹈知识、AI舞伴、艺术表达可打开。
- [ ] 教师工作区原有录入、导入导出功能可用。

## C. 教师标准视频
- [ ] 创建课程。
- [ ] 使用本人录制的10—30秒视频上传。
- [ ] 合法视频进入分析任务并显示进度。
- [ ] 识别完成后显示抽样帧数、检测帧数和检测比例。
- [ ] 显示骨架联系表，能够下载姿态JSON和骨架预览视频。
- [ ] 能播放原始视频并设置片段起止时间。
- [ ] 能添加片段名称和教师讲解。
- [ ] 新建片段默认为待审核。
- [ ] 教师确认片段后才能发布课程。

## D. 学员练习与对照
- [ ] 学员端只显示已发布课程和已审核片段。
- [ ] 学员上传前必须勾选知情同意。
- [ ] 学员视频成功分析后显示姿态预览。
- [ ] 标准视频和练习视频可并排播放。
- [ ] 两边骨架联系表可查看。
- [ ] 页面明确说明并排对照不是自动评分。

## E. 隐私和删除
- [ ] 上传前有知情同意提示。
- [ ] 原始视频保存在本地storage/uploads。
- [ ] 访问`/app.py`、`/.env`、`/requirements.txt`、`/data/sample_course.json`应为404。
- [ ] 删除练习视频后原视频和分析目录均被删除。
- [ ] 删除课程后关联视频、练习视频和分析结果均被删除。
- [ ] 本地服务只绑定127.0.0.1，不向公网开放。

## F. 试点真实素材
- [ ] 教师提供本人标准视频。
- [ ] 先只用教师本人视频验证，不先收集学员视频。
- [ ] 学员视频测试前单独告知用途并取得明确同意。
- [ ] 记录失败样本，不把算法检测比例宣传为舞姿准确率。
