舞伴智练 V1.4｜集成视觉识别本地试点版
====================================

这是什么版本？
--------------
本版本把原 V1.3 的学习页面、动作精讲、记忆陪练、现代舞知识、AI舞伴和教师工作区保留下来，并在同一个本地网页中增加 AI 视频识别与动作对照试点。

当前已经纳入的功能
------------------
1. 保留 V1.3：动作精讲、分段记忆、动作衔接、自评记录、现代舞知识、AI舞伴、教师工作区。
2. 教师端：创建课程、上传标准示范视频、AI提取33个人体姿态关键点、生成骨架预览与JSON。
3. 教师审核：手动填写动作片段起止时间、动作名称和讲解；片段需教师确认后才能发布。
4. 学员端：选择已发布课程与片段，上传自己的练习视频。
5. 视频对照：标准视频与练习视频并排播放，分别查看姿态骨架抽样预览。
6. 隐私管理：视频保存在本机私有目录；提供删除课程/视频/分析结果的入口。

本版本没有做什么
----------------
- 不做实时摄像头纠错。
- 不自动理解动作名称、编舞含义或艺术表达。
- 不输出动作总分、舞姿排名或“标准/错误”结论。
- 不做医疗、康复或身体状况判断。
- 不含账号系统、跨设备同步、云端视频存储和支付。
- 不含大学生兼职人才市场、活动报名和旅游服务；这些属于后续阶段。

运行环境
--------
必须使用 Python 3.12（64-bit）运行视觉识别模块。你之前的 Python 3.15 环境不要删除；本项目会创建独立的 .venv，不会覆盖旧项目。

Windows启动方式
---------------
1. 解压整个压缩包到一个新文件夹，不要覆盖旧 V1.3 文件夹。
2. 如果电脑还没有 Python 3.12，先安装 Python 3.12（64-bit）：
   https://www.python.org/downloads/windows/
   安装时勾选 Add Python to PATH。
3. 双击 start_windows.bat。
4. 首次运行会自动创建独立环境、安装依赖、下载姿态模型并启动网页；过程可能需要几分钟。
5. 浏览器打开 http://127.0.0.1:8011 。新V1.4使用8011端口，原V1.3的8000端口可以保留，不必覆盖旧版本。
6. 点击顶部“AI视频识别”进入新功能。
7. 首轮只用教师本人录制的10—30秒标准示范视频测试。

关闭方式
--------
关闭浏览器不会停止程序。要停止服务，请回到黑色命令窗口按 Ctrl+C；或关闭该窗口。

视频拍摄要求
------------
- 画面中尽量只有一位舞者；全身和双脚完整可见。
- 手机固定，不跟拍、不变焦；光线均匀、背景简单。
- 建议 MP4（H.264）、720p或1080p，10—30秒，当前最长60秒。
- 教师与学员视频尽量使用相同机位、方向和镜像状态。

隐私和安全
----------
- 首轮请只用教师本人视频。上传任何学员视频前，必须先告知用途并取得明确同意。
- 视频只保存在运行本程序的电脑本地，不会自动上传云端或第三方大模型。
- 视频文件名使用随机ID，原始视频不放在公开静态目录。
- 页面提供删除入口；删除课程会连同该课程关联视频和分析结果一起删除。
- 请勿把视频、数据库、.env或API密钥发到公开平台。
- 当前只绑定 127.0.0.1，不可直接对公网开放。

模型下载地址（自动下载失败时使用）
----------------------------------
https://huggingface.co/litert-community/MediaPipe-PoseLandmarker-Lite/resolve/main/pose_landmarker_lite.task
下载后保存为：models\pose_landmarker_lite.task

常见问题
--------
1. 提示没有 Python 3.12：安装 Python 3.12（64-bit）后重新运行 start_windows.bat。
2. 安装依赖失败：保持网络连接，重新运行 start_windows.bat；如仍失败，发送黑色窗口最后20行截图。
3. 模型下载失败：检查网络，按上面的地址手动下载到 models 文件夹。
4. 识别不到人体：检查全身是否入镜、光线、遮挡、视频清晰度和镜头方向。
5. 视频能识别但动作预览看起来不准确：关键点是算法估计；请教师核对，不要把识别比例当作动作评分。
6. 端口8011被占用：先关闭旧的舞伴智练窗口，或联系ChatGPT调整端口。
