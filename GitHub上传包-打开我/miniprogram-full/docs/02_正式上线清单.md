## 一、必须你本人完成的三件事

### 1. 注册并认证小程序

- 地址：https://mp.weixin.qq.com
- 点「立即注册」→ 选「小程序」→ 用邮箱注册。
- **主体类型建议选企业或个体工商户**：个人主体不能开通微信支付，部分服务类目也受限制。
- 企业主体需要微信认证，认证费 **300 元/年**（以官方实时价格为准）。
- 认证通过后，在「开发管理 → 开发设置」里拿到 **AppID**。

### 2. 小程序备案

- 2024 年起，小程序上线前必须完成工信部备案。
- 在微信公众平台「设置 → 小程序备案」里按指引提交，通常需要 1—20 个工作日。
- 需要主体证件、负责人核验等，**必须你本人配合做人脸核验**。

### 3. 买云资源

| 资源 | 用途 | 大致费用（以官网实时价为准） |
|---|---|---|
| 云服务器（腾讯云轻量 2核2G 起步） | 跑后端和 AI 识别 | 新用户活动约 100—300 元/年 |
| 域名 | 小程序请求的合法域名 | 约 50—100 元/年 |
| SSL 证书 | HTTPS 必需 | 云厂商有免费证书 |

> 服务器和域名都买腾讯云最省事，因为证书和备案指引都在一个后台。

## 二、部署后端（技术活，可找懂技术的人照着做）

### 2.1 上传代码

把 `server` 文件夹整个传到服务器，比如 `/root/wuban/server`。

### 2.2 准备模型文件

在服务器上下载姿态模型，放到 `server/models/pose_landmarker_lite.task`：

```bash
mkdir -p models
wget -O models/pose_landmarker_lite.task \
  https://huggingface.co/litert-community/MediaPipe-PoseLandmarker-Lite/resolve/main/pose_landmarker_lite.task
```

国内服务器如果访问 HuggingFace 慢，可以在自己电脑下载好，用 SCP 传上去。

### 2.3 配置环境变量

```bash
cp .env.example .env
nano .env
```

在 `.env` 里设置：

```
PILOT_CODE=一个只有你知道的邀请码
```

> 不设邀请码的话，任何人知道服务器地址就能用。上线前**强烈建议设一个**。
> 正式做用户系统时，应改为微信登录鉴权（当前是试点期简化方案）。

### 2.4 用 Docker 启动

```bash
docker compose up -d --build
```

检查是否成功：

```bash
curl http://127.0.0.1:8011/api/health
```

看到 `"ok": true` 就成功了。

### 2.5 配 HTTPS（小程序强制要求）

小程序只能请求 `https://` 域名。用 Nginx 反向代理到 8011 端口，配置示例：

```nginx
server {
    listen 443 ssl;
    server_name 你的域名.com;

    ssl_certificate     /路径/证书.pem;
    ssl_certificate_key /路径/私钥.key;

    client_max_body_size 120m;   # 视频最大 100MB，这里要留余量

    location / {
        proxy_pass http://127.0.0.1:8011;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 300s;
    }
}
```

把 `你的域名.com` 换成你买的域名，证书路径换成云厂商给你的实际路径。

## 三、小程序后台配置（这一步很关键，漏了就请求不通）

在 https://mp.weixin.qq.com 登录后：

### 3.1 服务器域名

「开发管理 → 开发设置 → 服务器域名」里，下面三项**都填** `https://你的域名.com`：

- `request 合法域名`
- `uploadFile 合法域名`（学员上传视频要用）
- `downloadFile 合法域名`（播放视频要用）

> 域名必须已完成 ICP 备案，且不能用 IP 地址。

### 3.2 用户隐私保护指引

「设置 → 用户隐私保护指引」里，按实际功能勾选并填写：

- 相机 / 相册（录制和选择练习视频）
- 视频（上传与分析）

小程序首次启动时，微信会按这份指引弹授权框。**不配置的话，调用相机/相册接口会失败，审核也会驳回。**

### 3.3 服务类目

「设置 → 基本设置 → 服务类目」：

- 如果定位是「舞蹈学习工具 / 内容展示」，通常选 **工具** 或 **教育-教育信息服务** 类目。
- 如果涉及在线培训、教学服务撮合，可能需要 **《办学许可证》** 等资质。

⚠️ **具体选哪个类目、要不要资质，以微信公众平台提交时的最新要求为准。**
建议先准备「工具」类目方案，同时咨询微信客服确认，避免被驳回。

## 四、把前端改成正式版并提审

1. 打开 `miniprogram/project.config.json`：
   - `"appid": "touristappid"` → 换成你的真实 AppID
   - `"urlCheck": false` → 改成 `true`
2. 用微信开发者工具打开 `miniprogram` 目录。
3. 右上角点「上传」，填版本号（如 `1.0.0`）和备注。
4. 回到公众平台「版本管理 → 开发版本」，找到刚上传的版本，点「提交审核」。
5. 审核通过后，点「发布」。

> 首次提审一般 1—3 个工作日。被驳回时，把驳回意见原文带回来，我帮你逐条改。

## 六、合规红线（别踩）

- 上传他人影像前必须取得对方同意；不做人脸识别，不比较身材/体型/年龄/外貌。
- AI 结果只做辅助观察，**不输出标准度百分比、不排名、不作医疗判断**。
- 动作名称、方向、重心等专业内容必须由教师审核后发布。
- 不诱导分享、不强制关注。
- 高校人才服务（教学撮合、报酬结算）属于后续阶段，首版**没有**这些功能，不要对外宣称已具备。
