# 舞伴智练｜微信小程序实验版

这是舞伴智练项目包中的手机端实验前端，配套 FastAPI 后端。它服务于第一阶段“教师建课—学员练习—动作对照—AI陪伴”的原型验证，不是已经审核发布的微信小程序。

## 页面

- 首页
- 课程
- 课程详情
- 练习
- 动作对照
- AI 聊天
- 学习记录
- 我的

## 与 V2.2 产品规划的关系

当前小程序代码主要覆盖学员学习闭环的页面和后端接口联调。教师课程创建、示范视频姿态分析、动作片段手动审核/发布，主要通过 `server/index.html` 的集成网页教师工作区完成。

高校舞蹈人才注册审核、社区需求发布、人才匹配、服务评价与结算尚未开发；小程序当前也没有正式支付、正式微信登录和生产级权限系统。

## 本机试点

1. 阅读 `docs/01_本机试点指南.md`。
2. 在 Windows 电脑按指南启动 `server/start_windows.bat`。
3. 使用微信开发者工具导入 `miniprogram/`。
4. 电脑和手机连同一 Wi-Fi，按指南设置本机后端地址。

## 正式上线前

必须完成微信登录、服务端会话、权限隔离、HTTPS、合法域名、隐私告知、数据删除与保留机制、微信审核和备案等事项。请阅读 `docs/02_正式上线清单.md`。
