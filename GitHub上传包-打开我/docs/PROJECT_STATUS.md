## 四、当前数据情况

### 轻量网页 `webapp/`
- 不创建账号和云端用户档案。
- 视频、姿态帧和聊天状态在当前浏览器页面中处理。
- 没有后台点击统计或用户分析仪表盘。

### 集成网页 `miniprogram-full/server/`
- SQLite 保存课程、片段、任务和对照等元数据。
- 原始视频与分析结果保存在运行服务的本机目录。
- 试点身份方案不是正式账号体系；当前没有生产级多用户权限隔离和云端同步。

### 微信小程序实验版
- 需要连接本机或配置的 FastAPI 服务。
- 当前为试点开发版，不是正式上线产品。
