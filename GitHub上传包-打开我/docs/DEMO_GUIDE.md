# 舞伴智练｜现场演示脚本（建议 6—8 分钟）

## 演示前准备

- 在 Windows 电脑启动 `miniprogram-full/server/start_windows.bat`。
- 浏览器打开 `http://127.0.0.1:8011`。
- 准备一段 10—30 秒、单人全身入镜的教师示范 MP4，以及一段相近机位的练习视频。
- 首次运行需要 Python 3.12（64 位）、依赖和姿态模型；提前测试，不要现场第一次安装。
- 说明视频使用授权，尽量使用本人录制或明确授权的测试素材。

## 演示顺序

### 1. 先讲产品定位（约 40 秒）

“舞伴智练面向社区中老年舞蹈爱好者，以现代舞学习为切入点。产品方向有 AI 动作指导、AI 情感陪伴、高校—社区资源连接三大支柱。今天演示的是第一阶段核心学习闭环原型，高校人才服务目前仍在规划。”

### 2. 教师上传标准示范（约 1 分钟）

- 点击“AI视频识别”。
- 创建课程，选择舞种，上传教师示范视频并确认授权。
- 等待分析完成，展示姿态检测比例、骨架预览和关键帧联系表。
- 说明：这是人体姿态关键点估计，不是舞蹈评分。

### 3. 教师手动切分与审核（约 1 分钟）

- 在原视频播放器中定位一段动作。
- 设置开始/结束时间，填写动作片段名称和教学讲解。
- 保存为待审核片段，点击教师确认。
- 发布课程。
- 强调：目前由教师手动选段并审核，系统还没有自动理解舞蹈语义。

### 4. 学员上传练习并查看对照（约 1—2 分钟）

- 在学员端选择刚发布的课程和已审核片段。
- 选择练习视频并确认授权。
- 等待分析完成，展示示范与练习视频、骨架联系表。
- 说明：当前主要帮助观察可见差异，不自动给出权威评分或纠错指令。

### 5. 展示动作学习和 AI 陪伴（约 1 分钟）

- 展示“动作精讲”“记忆陪练”“舞蹈知识”等页面。
- 进入 AI 舞伴，提问“动作总是记不住怎么办？”并追问一次。
- 展示回答边界：动作标准由教师确认；AI 不代替教师和医疗专业人员。
- 如果使用在线模型，必须说明已配置在线服务；未配置时按本地知识模式介绍。

### 6. 讲清楚后续计划（约 40 秒）

“下一步先用 3—5 名真实社区用户测试操作是否容易、动作对照是否看得懂、陪伴回答是否有帮助。高校—社区资源连接会在需求访谈和合作试点后再开发，不会把规划功能说成已经上线。”

## 现场不要这样说

- 不要说“AI 自动拆解所有舞蹈动作”——当前片段由教师手动划分。
- 不要说“AI 给动作打分/判断标准”——当前没有权威评分。
- 不要说“AI 陪伴已完全个性化”——当前是基础知识答复/可选在线模型。
- 不要说“高校人才平台已经上线”——该模块尚未开发。
- 不要把接口 mock 测试结果说成真实视频识别准确率。
