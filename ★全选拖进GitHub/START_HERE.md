# 从这里开始｜舞伴智练

这份项目包有三套代码，**第一次演示建议先用集成网页原型**，不要一上来就配置微信小程序。

## 推荐顺序

1. **先读产品状态**：打开 `docs/PRODUCT_ALIGNMENT_V2.2.md`，了解产品介绍中的功能哪些已经有原型、哪些还没开发。
2. **启动集成网页**：进入 `miniprogram-full/server/`，按 `../docs/01_本机试点指南.md` 的 Windows 步骤运行 `start_windows.bat`。成功后打开 `http://127.0.0.1:8011`。
3. **完成教师—学员闭环**：教师建课、上传示范视频、查看姿态识别、手动切分和审核动作片段、发布；学员再上传练习视频进行对照。
4. **备用演示**：若暂时不准备安装 Python 3.12，可先使用 `webapp/` 的轻量四功能版本：在该目录启动 `python -m http.server 8080`，打开 `http://127.0.0.1:8080`。
5. **最后再看小程序**：`miniprogram-full/miniprogram/` 需要微信开发者工具和后端服务，属于实验版。

## 重要提醒

- ZIP 是项目源代码和资料，不是双击就能安装的 Windows 安装包，也不是已上线网址。
- 本次代码/API检查已通过，但本次测试环境没有 MediaPipe，真实视频姿态识别尚未验收；请按 Windows Python 3.12 启动步骤完成实际模型验证。详见 `docs/RUN_VERIFICATION.md`。
- 集成网页的真实视频姿态识别需要 Python 3.12（64 位）、MediaPipe 依赖和模型文件；首次启动可能下载依赖和模型。
- 当前测试中的视频识别 API 测试使用模拟函数，真实视频识别需要在目标电脑上手动验收。
- 当前没有高校人才注册/审核/匹配平台，也没有正式账号、支付或云端运营后台。
- 先不要把用户视频、个人信息、密钥或本机数据库上传到公开 GitHub。
