## 一、项目概况

| 项 | 内容 |
|---|---|
| 项目名 | 舞伴智练（学员核心闭环试点版） |
| 主体类型 | 待定：试点期用微信开发者工具测试号；正式上线建议企业/个体工商户主体 |
| AppID 环境 | 测试环境：测试号（未配置真实 AppID）；正式环境：未配置 |
| 产品定位 | 面向社区中老年舞蹈爱好者的 AI 学习连接器，首版只做学员端 |
| 首版范围 | 课程学习 → 录/传视频 → AI 动作对照 → AI 陪伴 → 学习记录 |
| 当前阶段 | 页面与组件实现（3/6），已完成，进入联调验证阶段 |
| 关键约束 | 教师示范视频由用户提供；动作语义必须教师审核；不输出动作评分 |

## 二、技术栈

| 层 | 方案 |
|---|---|
| 小程序前端 | 微信原生框架，JavaScript，无第三方 UI 库（适老化自定义样式） |
| 后端 | FastAPI（基于 V1.4 源码，版本 1.4.1） |
| 视觉识别 | Python 3.12 + MediaPipe Pose Landmarker + OpenCV，服务端执行 |
| 数据库 | SQLite（试点）；正式多用户阶段建议迁移 PostgreSQL |
| 身份 | 试点期：昵称 + 邀请码换内存 token；正式版应改微信登录 |
| 部署 | 本机 Windows bat / 云服务器 Docker Compose |

## 四、已用组件与接口

### 微信能力
| 能力 | 用途 | 基础库/合规说明 |
|---|---|---|
| `wx.chooseMedia` | 录制/选择练习视频 | 替代已废弃的 `wx.chooseImage`；需配置隐私保护指引 |
| `wx.uploadFile` | 上传视频到后端 | 需配置 uploadFile 合法域名 |
| `wx.request` | 所有业务接口 | 需配置 request 合法域名 |
| `video` 组件 | 播放教师/学员视频 | 需配置 downloadFile 合法域名 |
| `wx.getStorageSync` | 昵称、token、服务器地址、练习记录 | 不涉及敏感个人信息 |
| `wx.showModal`（editable） | 昵称/邀请码/服务器地址输入 | — |

> 基础库具体版本要求需以微信官方文档核实；本项目的 API 均为长期稳定接口。

### 服务端接口约定
| 方法 | 路径 | 前端调用点 |
|---|---|---|
| GET | `/api/health` | 首页连接检查 |
| POST | `/api/pilot/join` | 我的 → 昵称与邀请码 |
| GET | `/api/courses?published_only=true` | 课程列表、课程详情 |
| POST | `/api/student/practices` | 课程详情 → 上传练习视频 |
| GET | `/api/vision/jobs/{id}` | 练习页状态轮询 |
| DELETE | `/api/vision/jobs/{id}` | 练习页删除 |
| POST | `/api/student/comparisons` | 对照页首次生成 |
| GET | `/api/student/comparisons/{id}` | 对照页再次进入 |
| POST | `/api/chat` | AI 陪伴 |

身份传递：请求头 `X-Pilot-Token`，同时在 URL 追加 `?token=`，供 video/image 组件使用。
