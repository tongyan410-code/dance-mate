# 舞伴智练 · 本机试点指南

这份文档的目标：**今天就在你手机上把小程序打开，能看课、能录视频、能看 AI 对照。**
不用买服务器，不用注册小程序账号，不用备案。前提是电脑和手机连**同一个 WiFi**。

---

## 第 0 步：准备四样东西

| 要准备什么 | 说明 |
|---|---|
| 一台 Windows 电脑 | 用来跑后端服务，过程中不要关机、不要关掉那个黑色窗口 |
| Python 3.12（64 位） | 如果电脑还没有，双击安装：https://www.python.org/downloads/windows/ ，安装时**勾选 Add Python to PATH** |
| 微信开发者工具 | 下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html ，装稳定版 |
| 一部手机 | 和电脑连同一个 WiFi，微信扫码用 |

> 你的 Python 3.15 不用删，这个项目会自己建一个独立环境，互不干扰。

---

## 第 1 步：启动后端（双击一下就行）

1. 打开文件夹：`D:\💗\舞伴智练_小程序\server`
2. 找到 **`start_windows.bat`**，双击。
3. 第一次运行会自动装依赖、下载姿态识别模型，可能要等几分钟。屏幕上会依次出现 `[1/4]`、`[2/4]`、`[3/4]`、`[4/4]`。
4. 看到 `[4/4] 启动舞伴智练……` 并且出现 `Uvicorn running on http://0.0.0.0:8011`，说明成功了。
5. **这个黑色窗口不要关**，关了服务就停了。

如果提示模型下载失败：手动打开
`https://huggingface.co/litert-community/MediaPipe-PoseLandmarker-Lite/resolve/main/pose_landmarker_lite.task`
下载后放进 `server\models\pose_landmarker_lite.task`，再重新双击 bat。

---

## 第 2 步：查出电脑的 WiFi 地址

1. 按 `Win + R`，输入 `cmd`，回车。
2. 在黑窗口里输入 `ipconfig`，回车。
3. 找到「无线局域网适配器 WLAN」下面的 **IPv4 地址**，比如 `192.168.1.23`。

> 手机必须用 WiFi 连到同一个路由器，不能用流量。

---

## 第 3 步：把小程序导入开发者工具

1. 打开微信开发者工具，点 **导入项目**（或「新建项目」→ 导入）。
2. 项目目录选：`D:\💗\舞伴智练_小程序\miniprogram`
3. AppID 那里选 **测试号**（不用填你自己的 AppID）。
4. 项目名称随便填，比如「舞伴智练试点」。
5. 点「确定」。

导入后如果提示校验域名，去右上角 **详情 → 本地设置**，勾选：
**「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**。
（本机试点用的是 http 地址，必须勾这个；正式上线后要改回来。）

---

## 第 4 步：在小程序里填服务器地址

1. 在开发者工具模拟器里，点底部 **「我的」**。
2. 点 **「服务器设置」**，把地址改成第 2 步查到的 IP，例如：

   ```
   http://192.168.1.23:8011
   ```

   注意：要带 `http://`，末尾不要斜杠，端口 `8011` 不能少。
3. 点确定，会提示「已保存」。
4. 回到 **「首页」**，看「服务器状态」是否显示**已连接**。

> 如果显示未连接：检查电脑防火墙有没有放行 8011 端口；确认黑色窗口还开着；确认手机和电脑在同一 WiFi。

---

## 第 5 步：设置昵称

在 **「我的」→「昵称与邀请码」** 里填一个昵称（比如「王老师」）。
试点版邀请码留空即可，直接确定。

---

## 第 6 步：教师先用电脑建一门课

小程序里现在还没有课程，需要先让教师在电脑上建课：

1. 在电脑上打开浏览器，访问 `http://127.0.0.1:8011`
2. 这是 V1.4 自带的网页版教师工作区。流程是：
   创建课程 → 上传教师示范视频（10—30 秒）→ 等 AI 分析完成 → 手动填动作片段的起止时间和讲解 → 教师确认 → **发布课程**。
3. 视频要求：一人、全身和双脚入镜、手机固定、光线均匀，MP4 最好。

> 只有**发布**过的课程，学员小程序里才看得到。

---

## 第 7 步：手机上真机试用

1. 开发者工具顶部点 **「预览」**，出现二维码。
2. 手机微信扫码，打开小程序。
3. 手机上的「我的 → 服务器设置」也要填成同一个 `http://电脑IP:8011`。
4. 进「课程」→ 选一门课 → 点某个动作的「练习这个片段」→ 录 10—30 秒视频 → 在「练习」里等分析完成 → 点「查看对照」。

---

## 出问题怎么办

| 现象 | 怎么处理 |
|---|---|
| 首页显示「未连接」 | 黑色窗口是否还开着？IP 是否填对？电脑防火墙是否放行 8011？手机是否同一 WiFi？ |
| 上传视频失败 | 视频是否超过 100MB 或 60 秒？换成 10—30 秒的 MP4 再试 |
| 分析失败 | 检查是否全身入镜、光线够亮、只有一个人；AI 识别不了会明确报失败原因 |
| 看不了骨架图 | 姿态模型可能没装好，回到第 1 步检查 `models` 文件夹 |
| 开发者工具报错 | 确认「详情 → 本地设置」里勾选了「不校验合法域名」 |

---

## 这一步做到什么程度算成功

- 手机上能打开小程序，首页显示「已连接」
- 能看到至少一门已发布课程
- 能录一段 10—30 秒视频并上传成功
- 「练习」页能看到分析完成，点开能并排播放教师示范和自己的练习

做到这四条，核心学习闭环就跑通了，可以拿给 3—5 位真实学员试用了。
