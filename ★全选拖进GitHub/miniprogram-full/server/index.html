V1.4 · LOCAL VISUAL PILOT

AI舞蹈视频识别与动作对照

教师先上传标准示范视频，AI提取人体姿态关键点并生成骨架预览；教师手动划分、讲解并审核片段后，学员才可以上传练习视频进行并排对照。

本版本为本机单人试点工具：只支持录制后上传的视频，不做实时纠错；AI识别人体姿态，不自动理解动作名称、不评判舞蹈审美，也不输出动作总分。请先使用教师本人录制的视频测试。

拍摄与隐私提示

  • 尽量只拍一位舞者，全身与双脚完整可见。
  • 手机固定，不跟拍、不变焦；背景简单、光线均匀。
  • 建议MP4（H.264）、720p或1080p，首轮10—30秒，最长60秒。
  • 教师示范与学员练习尽量使用相同机位、方向和镜像状态。
  • 视频保存在本机私有目录，不会自动上传云端或第三方大模型。
  • 原始视频不通过公开静态目录访问；页面提供删除入口。
  • 首轮请先使用教师本人视频。上传学员视频前必须取得明确同意。
  • 关键点是算法估计，不是精密动作捕捉；遮挡、旋转和机位差异会影响结果。
