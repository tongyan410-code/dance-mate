# 舞伴智练集成网页与 FastAPI 后端

本目录是项目包中最接近 V2.2 第一阶段教师—学员学习闭环的可运行网页原型。

## 能演示什么

- 学习首页、动作精讲、分段记忆陪练、现代舞知识、AI 舞伴、艺术表达。
- 教师创建课程并上传标准示范视频。
- 后端使用 MediaPipe Pose Landmarker 抽样提取 33 个人体姿态关键点，生成时间戳 JSON、骨架预览和关键帧联系表。
- 教师手动选取动作片段起止时间，填写动作讲解，审核后发布课程。
- 学员选择已发布课程/片段，上传练习视频，查看并排视频与骨架预览。

## 重要边界

- 目前不是完整商业平台或公网服务。
- 动作片段由教师手动划分；AI 不自动理解舞蹈动作名称、编舞意图或艺术表达。
- 视频对照用于辅助观察，不提供动作总分、专业舞姿评判或自动纠错口令。
- AI 聊天默认使用本地知识模式；只有在服务端配置 `AI_BASE_URL`、`AI_API_KEY` 和 `AI_MODEL` 后才会调用在线模型。
- 当前没有正式用户账号、生产级角色权限、多租户隔离和云端多设备学习档案。
- 高校—社区人才报名、审核、需求匹配、服务评价和结算尚未开发。

## Windows 启动

要求 Python 3.12（64 位）。双击 `start_windows.bat`，脚本会创建项目虚拟环境、安装依赖并尝试下载姿态模型。首次运行需要网络。服务启动后访问 `http://127.0.0.1:8011`。

如果模型下载失败，请按 `README_先看我.txt` 或 `V1.4手工验收清单.md` 的说明手动放入 `models/pose_landmarker_lite.task`。

## 测试

```bash
python -m pytest tests/ -q
```

当前接口测试中的视频分析函数使用 mock；测试通过不代表真实 MediaPipe 视频识别已在目标电脑完成验收。

## 数据位置

- 数据库：`data/vision.sqlite3`
- 原始视频：`storage/uploads/`
- 分析结果：`storage/results/`
- 姿态模型：`models/pose_landmarker_lite.task`

这些都是本机数据。不要将用户视频、数据库、密钥或真实个人信息上传 GitHub。
