【怎么上传到 GitHub】

1. 打开这个文件夹（就是你现在所在的文件夹）
2. 按键盘 Ctrl + A —— 会选中里面所有东西
3. 把选中的东西拖进 GitHub 网页那个虚线框
4. 拉到网页最底下，点「提交更改」
