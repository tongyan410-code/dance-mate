# 舞伴智练｜V2.2 产品方向对齐整理版

**产品定位：面向社区中老年舞蹈爱好者的 AI 学习与服务连接器。** 以现代舞学习为切入点，围绕 **AI 动作指导、AI 情感陪伴、高校—社区资源连接** 三大核心支柱，探索“学—练—评—陪—教—交流”的服务闭环。

> 产品主张：**AI 让动作更清楚，陪伴让学习更持续，连接让专业服务走进社区。**
>
> 重要说明：本仓库是当前原型代码与开发资料的整理包，不是已经完整实现 V2.2 所有规划的成品。当前重点是第一阶段核心学习闭环验证；高校—社区人才服务等内容仍属于后续规划。请以本 README 和 `docs/PRODUCT_ALIGNMENT_V2.2.md` 中的功能状态为准。

## 1. 这份项目包里有什么？

本项目保留了原有代码，并把最接近 V2.2 产品方向的集成网页作为主要演示入口，同时保留轻量网页和微信小程序实验版。

| 版本 | 所在目录 | 适合做什么 | 当前成熟度 |
|---|---|---|---|
| **集成网页原型（推荐主演示）** | `miniprogram-full/server/` | 教师建课、上传示范视频、姿态识别、教师手动拆分/讲解/审核/发布；学员上传练习并对照；动作精讲、舞蹈知识、AI 舞伴 | 本地试点原型，需安装 Python 3.12 和视觉依赖 |
| **轻量网页原型** | `webapp/` | 老师示范、我的练习、动作对照、AI 陪伴四项功能快速演示 | 浏览器本地运行；无后端、无账号、无后台统计 |
| **微信小程序实验版** | `miniprogram-full/miniprogram/` | 手机端课程、练习、对照、AI 聊天、记录等页面联调 | 开发/试点代码，未提交微信审核、未正式上线 |

如果你要向老师展示“产品如何从教师示范走到学员练习”，建议优先使用 **集成网页原型**。轻量网页适合作为备用演示，不要把两套原型的功能状态混为一谈。

## 2. 与 V2.2 产品介绍的对应关系

V2.2 规划包含三大核心支柱和五大功能模块。当前代码已经覆盖其中一部分，但并非全部完成。

| V2.2 功能方向 | 当前代码已有内容 | 状态 |
|---|---|---|
| 01 AI 视觉识别与动作拆解 | 集成网页后端可提取人体姿态关键点、时间戳、骨架预览和关键帧联系表；教师手动设置片段起止时间、填写讲解并审核发布 | **部分实现**：姿态提取已有原型；动作语义理解和自动动作分段未实现 |
| 02 舞蹈动作精讲与知识学习 | 有动作精讲、分段记忆练习、动作衔接、现代舞知识、艺术表达页面；教师可录入动作讲解 | **基础原型**：课程内容仍需教师持续补充、核对和完善 |
| 03 学员视频对照与 AI 智能陪练 | 学员选择已发布课程/片段，上传练习视频，提取姿态并查看并排视频与骨架预览 | **部分实现**：目前以视觉观察为主；没有可靠的自动时间轴对齐，也不提供动作总分或自动纠错指令 |
| 04 AI 情感陪伴与兴趣互动 | 轻量网页使用本地规则/知识库；集成网页后端可用本地知识模式，配置服务端密钥后可选接入在线模型 | **基础原型**：个性化复习、主动问候、打卡、成长档案和持续陪伴运营尚未完整实现 |
| 05 青年舞蹈人才服务 | 目前只有产品定位和后续规划文档 | **尚未开发**：没有人才注册审核、社区需求发布、岗位匹配、服务评价或结算 |

三大核心支柱状态：

- **AI 动作指导：** 已有姿态识别、教师手动分段审核、学员视频对照原型，仍需真实设备和真实舞蹈视频验收。
- **AI 情感陪伴：** 已有基础问答能力；轻量网页是本地规则/知识库，不是大语言模型。集成网页可选配置在线模型，但默认不代表已接入。
- **高校—社区资源连接：** 属于后续阶段，不在当前可运行功能范围内。

完整状态、技术边界和建议开发顺序见 [`docs/PRODUCT_ALIGNMENT_V2.2.md`](docs/PRODUCT_ALIGNMENT_V2.2.md)。

## 3. 推荐主演示：集成网页原型

目录：`miniprogram-full/server/`

它比轻量网页更接近 V2.2 的教师—学员流程：

1. 教师创建课程并上传标准示范视频。
2. 后端尝试提取姿态关键点，生成骨架预览、时间戳数据和关键帧联系表。
3. 教师播放原视频，**手动**设置动作片段起止时间，填写动作讲解。
4. 教师确认片段并发布课程。
5. 学员选择已发布课程和审核片段，上传自己的练习视频。
6. 系统提取学员视频姿态，提供两段视频和骨架预览供观察。
7. 学员可进入 AI 舞伴页面提问。

### Windows 本机启动

**运行要求：** Windows 电脑、Python 3.12（64 位）、可用网络（首次安装依赖/下载模型时需要）。当前包不含服务器端 MediaPipe 模型文件，启动脚本会尝试下载；如果下载失败，需要按启动说明手动放入模型。

1. 解压项目包。
2. 打开 `dance-mate/miniprogram-full/server/`。
3. 双击 `start_windows.bat`，按提示等待依赖安装和模型下载。
4. 看到服务启动提示后，在电脑浏览器打开 `http://127.0.0.1:8011`。
5. 保持命令窗口运行；关闭窗口会停止服务。

更详细步骤见 [`miniprogram-full/docs/01_本机试点指南.md`](miniprogram-full/docs/01_本机试点指南.md)。本机演示不等于公网部署；不要直接把本地服务暴露到互联网。

## 4. 轻量网页原型怎么运行

目录：`webapp/`

它不需要安装 npm 依赖，适合快速展示四项功能：老师示范、我的练习、动作对照、AI 陪伴。需要用本地静态服务器打开，摄像头功能通常要求 `localhost` 或 HTTPS。

```bash
cd webapp
python -m http.server 8080
```

浏览器打开 `http://127.0.0.1:8080`。该版本的人体姿态模型和 WASM 运行文件已放在 `webapp/` 目录中；AI 陪伴为本地规则/知识库答复，不调用在线大模型。

## 7. 用户数据：目前不是自动后台统计

- 轻量网页不具备用户账号和后台数据统计；视频、姿态结果和聊天状态在当前浏览器会话中处理。
- 集成网页后端会在本机 SQLite 和本机文件夹保存课程、任务、视频及识别结果；这不是云端多用户系统，也没有完整的运营分析后台。
- 第一阶段 3—5 名真实用户试用，建议使用 U01、U02 等匿名编号，由项目负责人使用表格记录任务完成情况、求助次数、用时、满意度和建议。
- 不要把用户视频、姓名、手机号、聊天隐私、邀请码、数据库或密钥上传到公开 GitHub。

试用方案见 [`docs/USER_TEST_PLAN.md`](docs/USER_TEST_PLAN.md)，记录模板见 [`docs/用户试用记录模板.xlsx`](docs/用户试用记录模板.xlsx)。

## 9. 隐私、安全与产品边界

- AI 姿态关键点是算法估计，不等于专业动作捕捉测量。
- 当前系统不提供权威舞蹈评分，不自动判断动作对错；动作名称、方向、编舞意图和教学标准由教师审核。
- 当前集成网页的课程、视频和分析文件保存在运行服务的本机；不要用于存放未经授权的他人影像。
- 正式公网部署前必须完成认证授权、访问控制、CORS 收紧、HTTPS、隐私告知、数据保留与删除机制、安全测试。
- 本项目未单独添加开放源代码许可证；公开 GitHub 不自动意味着允许他人商业使用或再发布。
